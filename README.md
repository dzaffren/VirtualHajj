## What it does

A virtual, interactive 3D space for learning Hajj procedures such as tawaf, sa'i and miqat.

## Install and run

| Task    | Command        |
| ------- | -------------- |
| install | `pnpm install` |
| run     | `pnpm dev`     |
| test    | `pnpm test`    |
| e2e     | `pnpm e2e`     |
| lint    | `pnpm lint`    |

## Features

- A learner opens a link on a phone or laptop and turns the camera round a plain Kaabah; `/perf` proves a scene holds 30 FPS.
